# 出纳

出纳负责公司资金的收付与记录，覆盖付款、收款、余额查询、回单管理、银行日记账与对账。日常操作通过建行企业网银完成，本栏目记录的是出纳的管理动作本身，网银只是载体。

## 流程

一笔支出从审批到入账的完整链路：

1. 审批：付款需求经审批确认，形成付款指令与收款信息；
2. 登记：收款信息登记进企业网银收款人名册，银行实时校验；
3. 制单：出纳从收款人名册选取收款账户，录入付款信息；
4. 复核：持有复核权限的人核对放行；
5. 支付：银行执行付款，资金离开公司账户；
6. 回单：银行生成电子回单，出纳下载归档；
7. 记账：回单作为凭据登记银行日记账；
8. 对账：定期与银行对账单核对，确认账实一致。

支付不是终点，清算不匹配的付款会被银行退回，资金沿原路回来，核实收款信息后重新登记、重付。收款链路与支出对称，场景确定后补充进来。

## 意图

1. 出纳不发起付款决策，只执行有审批依据的付款指令；
2. 收款信息以登记进名册并通过校验的那份为准，正文、附件等来源信息不直接用于付款；
3. 制单与复核由不同人完成，任何一笔付款不能由同一人全程办结；
4. 回单是付款完成的唯一凭据，没有回单的付款视为未完成；
5. 退回是支付的常态分支，付款成功不等于收款人到账，付出之后可能回到起点；
6. 流水随发生随登记，对账不留历史欠账。
